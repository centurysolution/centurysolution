How to use (quick guide)

1. Login — User ID + Password (Admin: husain@centurysolution.co.in).

2. Host online (free) — Cloudflare Pages or Netlify: upload this folder. See CLOUDFLARE_GUIDE.txt.

3. Shared users — put Supabase URL + anon key in config.js, redeploy, then Settings → Push.

4. Other devices — open the same site link and login with the user ID created by Admin.

5. One computer only — you can also open index.html locally without hosting.

Full steps: CLOUDFLARE_GUIDE.txt

Cloud & Team Share (v13)

Your data is saved in this browser. Export Team Package creates a file — store it on Google Drive / OneDrive / your server. Others can Import it and view the same data with their login.

Drive tip: Upload JSON → Share → anyone with link → use a direct-download link. Server: host the JSON on HTTPS.

Shared Database (Supabase — Free)

Cloudflare Pages / Netlify: host the folder online, set Supabase URL + key in config.js, redeploy, then Push. See CLOUDFLARE_GUIDE.txt.

Login on another device: (1) Save URL+key here (2) Push (3) put the same URL+key in config.js and re-upload the folder to Netlify (4) Push after creating each new user. Then login works on other devices.

Data Backup & Restore

All data stays in this browser until you clear it. Download a full backup regularly. Restore anytime.
