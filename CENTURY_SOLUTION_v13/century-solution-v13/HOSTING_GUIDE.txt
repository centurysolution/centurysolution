PART 1 — FREE APP HOSTING (Login page internet se)
=========================================================

Option A — Netlify Drop (SABSE AASAN, 2 minute)
-----------------------------------------------
1. Chrome me kholo: https://app.netlify.com/drop
2. Netlify account free banao (email se)
3. CENTURY SOLUTION ka POORA folder

   https://random-name.netlify.app

Option B — Cloudflare Pages (Free)
----------------------------------
1. https://pages.cloudflare.com
2. Sign up free
3. "Upload assets" / direct upload
4. Folder upload → link mil jayega

Option C — Company / own server
-------------------------------

  /var/www/century/   (example)

=========================================================
PART 2 — FREE SHARED DATABASE (Supabase)
=========================================================

1. Browser me kholo: https://supabase.com
2. "Start your project" → free account (GitHub/email)
3. New Project:
   - Name: century-solution
   - Database password: strong password SAVE KAR LO
   - Region: nearest (e.g. Mumbai/Singapore if available)
4. Project create hone do (1–2 min)

5. Left menu → SQL Editor → New query
   Ye SQL POORI copy-paste karke RUN dabao:

----- SQL START -----
create table if not exists public.cs_store (
  key text primary key,
  value text not null,
  updated_at timestamptz default now()
);
alter table public.cs_store enable row level security;
create policy "allow all anon" on public.cs_store
  for all using (true) with check (true);
----- SQL END -----

6. Left menu → Project Settings → API
   Yahan 2 cheezein copy karo:
   a) Project URL   → https://xxxxx.supabase.co
   b) anon public   → eyJhbGciOi...  (long key)

7. CENTURY SOLUTION me login (Admin)
   Settings → Shared Database (Supabase)
   - URL paste
   - anon key paste
   - Save Cloud Settings

8. Data upload:
   Settings → Push (Upload data)
   Success message aani chahiye

9. Doosre user / doosra phone:
   Same app link kholo → login
   Settings me SAME URL + key save
   → Pull (Download data)
   → Page reload → same data


DAILY USE (team)
----------------
- Admin / koi bhi important change ke baad → Push
- Subah kaam shuru → Pull (latest data)
- Best: ek person "data owner" Push kare, baaki Pull
